# MacCMS 10 功能对照与收尾清单

核对日期：2026-10-21。参考 [MacCMS 10 源码](https://github.com/magicblack/maccms10)。本项目使用 Cloudflare Workers、Pages、D1 和 R2；PHP 文件系统插件、原生服务器扩展等不直接兼容，需按边缘运行环境实现等价功能。

## 已完成的代码能力

- 视频、分类、文章、专题、漫画、网址、明星、角色等内容管理；批量操作、重复检测、回收站、导入导出，以及 MacCMS Provide JSON/XML 接口和定时采集。
- 会员、会员组、卡密、积分、VIP、播放记录、收藏/关注、签到、私信、优惠券、积分商城、秒杀、现金商城订单、提现登记和会员社区。
- 管理员角色与审计、统计、内容质检、任务、运行监控、媒体库、远程图片同步、主题参数和桌面/手机模板布局。
- 角色/剧情筛选、评分/顶踩；动态隐私、图片、评论、举报及管理员处置；删除被内容或会员动态引用的附件时会阻止操作。
- 新密码 PBKDF2 存储、旧密码登录后升级；会员资料、改密、逐集播放权限、文章权限/购买、跨设备播放进度与邀请奖励。
- Provide 数据翻译和前台语言选择；站点地图包含网址与直播频道。可选搜索热词面板默认关闭且不记录用户身份/IP。
- AI 内容简介/SEO 等审核建议、候选内容推荐、质量评分、匿名会员兴趣画像，以及可选语义搜索。AI/语义功能需配置兼容 API 并显式开启。
- 易支付 V1 收银台、MD5 回调验签、服务端订单查询对账、会员充值及商城现金订单；管理员可对已付款但未履约的商城订单申请原路退款。退款回调后库存、积分及优惠券会恢复。
- 可选 Cloudflare Turnstile 登录/注册校验；D1 静态内容页；按请求域名覆盖站点信息和独立桌面/手机主题；内置主题配色预设。
- R2 数据表 gzip 快照和管理员还原；服务端限时试看代理支持直接 MP4/HLS 源，且校验媒体源域名与重定向目标。

## 仍需生产环境配置或真实验收

- [ ] **易支付商户联调**：在后台填写 HTTPS 网关、PID、KEY 和可选支付方式，使用真实商户完成小额下单、异步通知、主动查询、退款与对账。代码已接入协议，但当前没有商户参数，不能代替真实交易验收。
- [ ] **Cloudflare 部署**：生产 D1 依序执行 `migrations/0021` 至 `0025`；确认 Worker/Pages 的 D1 与 R2 绑定、域名路由、定时任务和密钥。当前只做本地迁移。
- [ ] **SMTP 与 Web Push**：部署环境配置 SMTP、VAPID 密钥，验证邮件收发、订阅、投递和失效订阅清理。
- [ ] **媒体存储**：配置目标 Telegram Bot/频道或 Telegraph 凭据，验证上传、轮询、重试、预览及读取。
- [ ] **浏览器验收**：在目标桌面和手机浏览器走查响应式溢出、导航、播放器、主题、多语言和会员端到端流程。

## 有边界的能力

- R2 快照存到当前绑定的 `MEDIA_BUCKET`，每表最多 10,000 行；这是同一 Cloudflare 账号/桶中的快照，不是独立 S3/OSS/MinIO 异地备份。真正异地备份需另配存储端点和凭据。
- 强制试看只适用于可识别的直接 HTTPS MP4/HLS 源；解析器线路和跨域 iframe 不可被 Worker 检查内部播放时间或错误状态。
- 主题提供现有参数编辑和内置配色预设；没有任意 PHP 插件/模板在线安装市场。Workers 不提供安全执行任意上传 PHP 插件的运行时。
- 多域名共享同一 D1 内容库，只覆盖站点元数据和主题；没有每域独立数据库/内容分区。
- 与 MacCMS 10 的最终兼容度仍需根据具体主题、采集源和实际插件逐项核对；不能仅凭功能名称声称字节级或插件级完全兼容。
