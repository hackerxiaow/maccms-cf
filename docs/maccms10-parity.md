# MacCMS 10 功能对照

基准：MacCMS 10 官方仓库当前 `master` 与 v2026.1000.4056 发布说明；核对日期 2026-10-21。

参考：
- https://github.com/magicblack/maccms10
- https://github.com/magicblack/maccms10/releases
- https://github.com/magicblack/maccms10/commits/master

本项目运行在 Cloudflare Workers、D1、R2 上。目标是迁移对应的用户功能和管理流程；PHP 文件系统插件等能力需要按 Workers 运行模型实现等价版本，不能直接照搬 ThinkPHP 实现。

## 已有基础实现

- 视频、分类、文章、专题、漫画、网址、明星和角色的后台数据管理；视频批量操作、重复检测合并、回收站、JSON 导入导出。
- MacCMS `provide` 数据接口：视频、文章、演员、角色、网址、漫画；定时采集、资源站分类映射、播放器/下载器/服务器配置。
- 会员注册登录、会员组、卡密、积分、VIP、观看记录、收藏、关注、签到、私信、优惠券、积分商城、秒杀和订单管理。
- 留言、评论、广告、友链、直播、弹幕、聊天室、分享、URL 推送。
- 管理员角色、审计、访问统计、内容质检、任务、运行监控、R2 媒体库和主题参数配置。
- 本批补齐：分集剧情与角色的公开 API；会员资料修改与改密；受限播放/下载地址服务端逐集鉴权；会员跨设备播放进度；文章密码/会员组/积分权限及购买记录；新密码使用 PBKDF2，旧 SHA-256 账号登录成功后自动升级。
- 本批补齐：多 TG Bot 和单 Bot 多频道附件投递目标，按目标权重轮询；管理端附件图库、批量操作；远程图片分批同步与可恢复替换。
- 本批补齐：邀请码与邀请奖励配置；新会员注册时一次性奖励邀请人/受邀人积分；会员中心显示邀请码、分享链接及邀请记录。
- 本批补齐：SMTP 邮箱验证与密码找回、可选在线收银台回调、Web Push 通知、Meilisearch 索引、会员动态与钱包提现；管理端增加资源巡检、字段翻译，以及需人工审核的 AI 简介/元数据/SEO 建议。

## 未实现与待验收清单

以下清单区分代码缺口、与官方行为的待核对项，以及部署时需要提供的外部服务。Web Push/SMTP/支付等代码入口已存在；没有完成相应部署配置前，不能视为线上服务已启用。

### 代码功能待实现

- [ ] **响应式前台模板**：新的视频网站模板尚未开工；将首页、筛选、详情、播放、文章、专题、角色、分集剧情、会员中心和搜索统一适配桌面与手机，并接入现有主题配置。
- [ ] **角色与剧情交互**：核对并补齐 MacCMS 对应的筛选项、URL 规则、角色评分/顶踩；把现有角色和剧情页面接入新模板。
- [ ] **媒体附件覆盖**：商品与直播模型的附件字段尚未接入统一媒体库；需在浏览器中核验 R2、Telegram（多 Bot/多频道）和 Telegraph 上传、预览、删除及引用保护。
- [ ] **会员社区**：动态评论、动态图片/附件、举报和更细的隐私控制尚未实现。
- [ ] **AI 运营**：内容简介/元数据/SEO 建议已实现且需人工审核；AI 内容推荐、用户画像和质量评分未实现。
- [ ] **支付闭环**：当前是通用托管收银台协议，仍需具体支付服务商适配；商城现金订单、退款/撤销回调和原生渠道适配未实现。提现目前由管理员线下打款并登记。
- [ ] **搜索运营**：SQL 与可选 Meilisearch 检索已实现；语义/聊天搜索、热词统计面板和关键词运营调优未实现。
- [ ] **播放器**：播放源分辨率/清晰度选择未实现。试看由页面计时；只有把直接媒体源纳入服务端代理后，才能可靠强制截止。跨域 iframe 的内部播放失败状态受浏览器同源策略限制，不能保证自动探测。
- [ ] **安全风控**：已有针对主要会员操作的限流、会话撤销和访问规则；跨路由统一风控策略、验证码服务和异常行为评分未实现。
- [ ] **SEO 与多语言**：站点地图/订阅源及 URL 推送已覆盖主要内容；网址与直播路由仍需逐项核对。字段翻译目前覆盖 REST 列表/详情，尚未覆盖全部 Provide XML/JSON 接口和前台模板。
- [ ] **站点运维**：静态页面生成、S3/OSS/MinIO 异地备份、多域名/站群、独立移动站配置未实现。
- [ ] **主题与扩展**：模板市场、可视化主题设计器、受控扩展市场和在线安装流程未实现。

### 部署配置与真实环境验收

- [ ] **邮箱**：部署环境配置 SMTP 并完成收发验证；`worker-mailer` 代码和后台测试邮件入口已接入。
- [ ] **支付**：接入并验收真实支付服务商的收银台、回调签名、查询对账和退款协议；项目内置协议本身不等于已接通支付宝/微信。
- [ ] **推送/PWA**：生产站启用 HTTPS，生成并配置 VAPID 密钥，在目标浏览器验证订阅、投递和失效订阅清理。
- [ ] **Cloudflare 资源**：线上 D1 按序执行迁移，配置真实 D1/R2 绑定与密钥；本地 D1 已应用至 `0019_member_security.sql`。
- [ ] **存储后端**：配置目标 Bot、频道或 Telegraph 服务凭据，实测多目标轮询、失败重试和文件读取。
- [ ] **全流程验收**：在部署环境逐项走查后台权限、会员操作、付费订单、媒体库、移动端布局及静态模板资源加载。
