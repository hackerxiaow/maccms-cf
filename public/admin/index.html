💡 开放标准接口协议

本平台已原生实现 MacCMS 官方标准的资源开放互联体系：
• 视频采集接口 (Provide VOD)：/api.php/provide/vod/?ac=list (分类概要) 或 ?ac=videolist&h=24 (今日更新)
• 标准 RSS 5.1 XML 格式：追加 &at=xml 即可直接供外部采集器对接
• 文章采集接口 (Provide Art)：/api.php/provide/art/?ac=list
• 定时增量调度 (Timming API)：/api.php/timming/index?h=24
